# Следующий шаг после PRD

Порядок работы с агентом: сначала мышление, потом код, потом проверка. После готового PRD предложи автору проекта эти промпты по очереди (источник: https://prd-agentic-lab.vercel.app).

## Шаг 1. Понимание (первый промпт)

```
Прочитай PRD ниже. Пока не пиши код.

Сделай:
1. Кратко перескажи, что нужно построить.
2. Найди неоднозначности и задай вопросы.
3. Предложи план реализации для первой версии.
4. Явно перечисли, что не входит в scope.
5. Предложи критерии проверки результата.

После этого остановись и жди подтверждения.
```

## Шаг 2. Реализация (после плана)

```
Ок, реализуй только v1 из PRD. Не добавляй функции вне scope. После реализации обнови README и дай инструкцию, как проверить основной сценарий.
```

## Шаг 3. Проверка

```
После реализации проверь результат по критериям готовности из PRD. Если что-то не выполнено, перечисли конкретно. Не исправляй без моего подтверждения.
```

Подробнее и видео: https://prd-agentic-lab.vercel.app
