# Шаблон мини-PRD

Источник: https://prd-agentic-lab.vercel.app (AI-LAB). Заголовки и порядок блоков не менять.

```markdown
# PRD: [название проекта]

## Контекст

[Какая проблема есть сейчас? Почему эта штука нужна?]

## Цель v1

[Что нужно проверить или улучшить первой версией?]

## Пользователь

[Кто один главный пользователь первой версии? В каком контексте он использует продукт?]

## Основной сценарий

[Пользователь открывает... затем... затем... Важно описать один главный путь от начала до результата.]

## Функциональные требования

- [Пользователь может...]
- [Система показывает...]
- [Данные сохраняются...]

## Нефункциональные требования

- [Как запускать]
- [Где хранить данные]
- [Какие ограничения по стеку, сервисам, сложности]
- Если есть выбор между простым и масштабируемым, выбрать простое.

## Не входит в v1

- [Регистрация]
- [Оплаты]
- [Командная работа]
- [Интеграции]
- [Всё, что хочется добавить, но нельзя сейчас]

## Критерии готовности

- [Проект запускается по README]
- [Основной сценарий проходит вручную]
- [Нет ошибок в консоли в основном сценарии]
- [Данные сохраняются / результат создаётся / нужная проверка выполнена]

## Вопросы и риски

- [Что пока непонятно?]
- [Где агент может усложнить систему?]
- [Что будет, если AI вернёт плохой ответ?]
```

Строку «Если есть выбор между простым и масштабируемым, выбрать простое.» оставляй в каждом PRD, если ученик явно не решил иначе.
